# Turkey on the Run — The Great Escape to Freedom Forest

The R3 art uses a cream and vermilion chase poster, amber farm scenery, and deep green woods. The four bundled frames show the title, chase climax, forest approach, and escape. The caught ending remains available through gameplay and the `?shot=caught&seed=1` preview.

## Verification

- Scripted input through the production input handler and frame loop reached a catch at 167 m and an escape at 1,200 m with seed 1. Both runs exercised restart, mute, and pointer jump in a Node headless harness with DOM, Canvas, and Web Audio adapters.
- Chromium startup was blocked by the execution sandbox. The four JPEG previews use the game's Canvas drawing calls rasterized through SVG and Cairo. Browser font fallback and Canvas effects may vary slightly from the previews.
